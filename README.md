# Wealth Wisdom

A premium, interactive multi-step retirement planning assessment web application built with React, Vite, and Tailwind CSS.

## Features

- **Personal & Spouse Profiles**: Calculate auto-age and retirement metrics.
- **Lifestyle Goals accordion**: Multi-select travel planner, college planning database, and details calculators.
- **Current Savings Assessment**: Evaluate NPS, EPF, and Superannuation contributions.
- **Interactive Modals**: Special popups for Higher Education and Foreign Tour planning.
- **High-fidelity UI**: Montserrat typography, custom 3D illustrations, and vibrant responsive design.
